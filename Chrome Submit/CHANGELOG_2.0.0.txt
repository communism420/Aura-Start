What's new in 2.0.0
- Added nested groups up to two levels, including parent selection, indentation, drag-and-drop reparenting, and safe handling of child groups when deleting a parent group.
- Added fast fuzzy search across link titles, URLs, descriptions, and tags, with highlighted matches, result counts, quick filters, and Command Palette integration.
- Reworked restore points into a full Restore Timeline with day grouping, search, action filters, richer context, and confirmation before rollback.
- Added optional "Save open tabs" workflow with preview, duplicate URL filtering, runtime tabs permission request, and restore-point protection.
- Added background personalization with built-in backgrounds, custom local image upload, blur, dimming, and positioning controls.
- Added optional widgets: clock, local Markdown notes, and Pomodoro timer.
- Added Google Drive sync improvements, including Chrome appDataFolder sync and a device-code fallback for compatible Chromium browsers where built-in Google sign-in is unavailable.
- Added Firefox-oriented build support and cross-browser WebExtension API wrappers while keeping Chrome Web Store permissions minimal.
- Improved import, export, backup, and migration flows, including A Fine Start import/export compatibility and safer JSON validation.
- Improved drag-and-drop behavior for groups and links, including nested groups and link moves between groups.
- Added stronger destructive-action protection with restore points before imports, deletes, resets, group moves, tab saves, duplicate cleanup, and cloud restores.
- Updated onboarding, empty states, settings, privacy messaging, translations, documentation, and screenshots for the new 2.0.0 design.
