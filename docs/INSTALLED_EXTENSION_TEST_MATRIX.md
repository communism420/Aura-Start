## Two-Device Google Drive Sync — 2.1.0

Use two independent installed browser profiles/devices, A and B, connected to the same Google account with production OAuth clients from the same Google Cloud project. Run Chrome-to-Chrome and Chrome-to-Firefox/Device OAuth cases. Update both to the latest 2.1.0 build with the single-file protocol; back up each profile first. Record tested builds, browsers, elapsed propagation times, and pass/fail evidence. These are manual checks, not results already verified by unit tests.

Quiet metadata checks run about every five seconds while an Aura Start page is visible and online, shared across pages in the same profile. A background alarm also checks about once a minute, including with pages hidden or closed. Page opening, closing, focus, and visibility changes do not themselves request sync. Verified unchanged revisions skip payload/media transfers and last-sync-time writes; new or unverified revisions are read when needed. Failed passive checks back off up to a minute. Pending offline edits can recover on startup or an online event. Allow completed sync cycles and network latency; do not require delivery while the browser is fully closed or promise an exact deadline.
