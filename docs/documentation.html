Use Aura Start with confidence.

Practical guides for setting up your new tab and Firefox homepage, nesting groups, saving tabs, personalizing the page, recovering from mistakes, and understanding exactly where your data goes.

Local-first by default.

Aura Start works without an account. Your links stay in local extension storage unless you explicitly connect optional Google Drive sync. No Google account is required for local use or file backups.
